?- octal_code(A,B,C).
000
A = B, B = C, C = 0 ;
001
A = B, B = 0,
C = 1 ;
010
A = C, C = 0,
B = 1 ;
011
A = 0,
B = C, C = 1 ;
100
A = 1,
B = C, C = 0 ;
101
A = C, C = 1,
B = 0 ;
110
A = B, B = 1,
C = 0 ;
111
A = B, B = C, C = 1.

Because of backchaining, it first unifies bit(C) with bit(0) and A=B=C so its all 0
Then, it changes C to 1 to second solution. 
Then backchains since C has all options making A=C and B = 1
It then backchains again to where B=C and C=1, A=0.
From then on it keeps exploring all options and backchaining when solution is already found 
and exploring all different possible solutions within the conditions in the predicates
